# POLY LOOT V6.0

**The Ultimate Poly Loot Automation Script**

Poly Loot V6.0 is an advanced Roblox automation script designed to make farming, dungeon runs, and inventory management faster and more efficient.

Featuring a modern and user-friendly **OasisUI** interface, the script combines multiple automation tools into one powerful system.

## Features

### Dungeon Speedrun
- Automated Halloween Dungeon runs with 18 rooms.
- Automatic enemy targeting, combat, and navigation.
- Boss detection and automatic loot collection.
- Optional Auto Replay for continuous dungeon farming.
- Improved teleport safety and recovery mechanisms.

### Main World Auto Farm
- Farm specific enemies across all five Main World areas.
- Select your preferred area and enemy type.
- Automatic enemy tracking, attacking, and loot collection.
- Spawn-based targeting for consistent farming.

### World Boss Farm
- Automatically detect and farm World Bosses.
- Choose specific bosses from the selection menu.
- Automatic combat and loot collection.
- Boss respawn timer tracking.
- Knockback recovery and improved loot collection.

### Smart Auto Sell
- Automatically sell selected weapons and armor.
- Filter and select items by rarity and name.
- Customizable inventory capacity threshold (80–95%).
- Instant Sell button for manual selling.
- Built-in protection for favorited, locked, equipped, and other protected items.

### Additional Features
- **Anti-AFK** – Helps prevent idle disconnections while farming.
- **OasisUI** – Clean, modern, and organized interface.
- **24-Hour Key System** – Key-based access with automatic verification.
- **Optimized Automation** – Improved stability, navigation, and recovery systems.

## Getting Started

1. Execute the script using a compatible Roblox executor.
2. Obtain your free 24-hour access key.
3. Verify your key to unlock the interface.
4. Select your preferred farming mode and configure your settings.
5. Activate the desired automation features.
